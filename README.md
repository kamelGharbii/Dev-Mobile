# Dev Mobile - Travaux Pratiques (TPs) Android

Ce dépôt regroupe l'ensemble des travaux pratiques (TPs) réalisés dans le cadre du module **Développement Mobile** (Android / Java).

---

## 📁 Structure du Projet

Chaque TP est organisé dans un répertoire dédié et constitue un projet Android Studio complet :

| Dossier | Application | Description |
| :--- | :--- | :--- |
| [`TP1/`](./TP1) | **App Moyenne** | Application de saisie de notes et de calcul automatique de la moyenne avec mention. |
| [`TP2/`](./TP2) | **Quiz Calcul** | Jeu de quiz d'opérations arithmétiques avec gestion du score et réponses interactives. |
| [`TP3/`](./TP3) | **Conversion C/F** | Convertisseur de température instantané entre Celsius et Fahrenheit. |
| [`TP4/`](./TP4) | **Mastermind** | Jeu de réflexion et de déduction logique Mastermind sur Android. |
| [`TP5/`](./TP5) | **Convertisseur** | Application de conversion avec composants UI personnalisés. |
| [`TP6/`](./TP6) | **Système Commande Restaurant** | Application de prise de commande de restaurant avec sélection et calcul du total. |
| [`TP7/`](./TP7) | **ListView Simple** | Découverte et manipulation du composant `ListView` avec `ArrayAdapter`. |
| [`TP8/`](./TP8) | **ListView Personnalisée** | Création d'une `ListView` avancée avec un adaptateur personnalisé (`CustomAdapter`). |
| [`TP9/`](./TP9) | **ListView Produits** | Gestion et affichage dynamique d'un catalogue de produits avec `ListView`. |

---

## 🛠️ Prérequis et Technologies

- **Langage :** Java
- **Environnement :** Android Studio
- **Build System :** Gradle (Kotlin DSL / Groovy)
- **SDK minimum supporté :** Android SDK 24+ (Android 7.0+)

---

## 🚀 Utilisation

Pour tester un TP :
1. Cloner le dépôt :
   ```bash
   git clone https://github.com/kamelGharbii/Dev-Mobile.git
   ```
2. Ouvrir **Android Studio**.
3. Sélectionner **File > Open...** puis choisir le dossier du TP souhaité (ex: `TP1`).
4. Laisser Gradle synchroniser les dépendances.
5. Lancer l'application sur un émulateur ou un appareil Android connecté.
